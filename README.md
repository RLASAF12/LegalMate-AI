## Features
- **Conversational Guidance** - Ask legal questions in plain English and get clear, instant answers.
- **Document Explainer** - Upload legal papers and get a "plain language" breakdown of what they mean.
- **Task Management** - Track your legal-related tasks and upcoming deadlines in one place.
- **Smart Sourcing** - Links to official templates and jurisdiction-specific resources.

## Installation
```bash
npm install
```

## Quick Start
```bash
npm run dev
```

## Tech Stack
- **Frontend**: React, Vite, Tailwind CSS
- **State Management**: React Hooks & Context API
- **Design**: Shadcn UI / Lucide Icons

> [!TIP]
> Ask LegalMate to "Summarize for a 5-year-old" for an ultra-simple explanation of any legal concept.
